-----------NEXBYTE---------

This is a tech blog UI I built for my CCC probation task. The idea was to design something that actually looks like a real tech blog instead of just a basic HTML page - so I focused a lot on typography, spacing and making the article cards look clean.

Live link: https://vercel.com/jainanubha383-6516s-projects/nexbyte-techblog-jtlq/3Nwm5gbURq4ygJW83aceSXuAfrCU

The homepage has a featured article at the top and then a grid of the latest articles. There's also a sidebar with trending posts and popular tags. Each article on the homepage links to its own separate page where you can actually read the full content, instead of everything just going to the same page.

I tried to keep the design consistent across every page - same header, footer and color scheme everywhere so it feels like one connected site and not six random pages.

Files included :

- index.html - the homepage
- article-ai.html
- article-webdev.html
- article-cloud.html
- article-cyber.html
- article-opensource.html
- article-future.html
- style.css - all the styling

tech used: 

Just plain HTML and CSS, no frameworks. Used flexbox for the header/footer and layout stuff, and grid for the article cards on the homepage.

My focus was on :

- Getting the line-height and font sizes right so the articles are actually readable and not cramped
- Card hover effects so it feels a bit more interactive
- Making the trending sidebar look different from the main article cards so the page doesn't feel repetitive
